This repository documents my hands-on journey through **AWS database services**, focusing on real-world use cases, security best practices, and production-style workflows. **Folder:** `01-Intro_to_database_series`

### 02️⃣ Amazon Aurora – Web Application Connection

**Folder:** `02-Amazon-aurora-webapp-connection`

**What I did:**

* Connected a web application to Aurora
* Configured networking and access controls

**Skills demonstrated:**

* Amazon Aurora & RDS
* Application-to-database connectivity
* Networking and security groups

### 03️⃣ DynamoDB – Load Data Using AWS CLI

**Folder:** `03-Aws-dynamodb-load-data`

**What I did:**

* Practiced schema-less NoSQL design

**Skills demonstrated:**

* DynamoDB fundamentals
* AWS CLI
* NoSQL data modeling

---

### 04️⃣ DynamoDB – Queries & Transactions

**Folder:** `05-Aws-dynamodb-queries`

**What I did:**

* Queried DynamoDB tables using partition and sort keys
* Used AWS CLI and Management Console
* Implemented DynamoDB transactions for atomic operations

**Key learning:**

* DynamoDB queries must be designed around access patterns
* Transactions ensure data consistency across multiple operations

**Skills demonstrated:**

* Advanced DynamoDB querying
* Transactions
* CLI-based troubleshooting

---

### 05️⃣ Visualizing Relational Data with RDS & QuickSight

**Folder:** `06-Aws-databases-visualization`

**What I did:**

* Created and populated an Amazon RDS (MySQL) instance
* Connected RDS to Amazon QuickSight
* Secured database access using private networking and security groups

**Key learning:**

* Public databases are risky
* Secure access should use dedicated security groups and least privilege

**Skills demonstrated:**

* Amazon RDS
* Data visualization (QuickSight)
* Cloud security best practices
