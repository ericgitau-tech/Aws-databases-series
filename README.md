# AWS Database Series 🚀

This repository contains a hands-on series of projects focused on building and working with databases in AWS.

The projects are designed to give practical experience with both relational and NoSQL databases, including connecting applications, loading data, running queries, and visualizing insights.

Each module builds real-world cloud database skills needed for modern applications.

---

## 📌 Project Series

### 01 - Introduction to AWS Databases
Overview of AWS database services and the project series structure.

### 02 - Amazon Aurora Web App Connection
Connect a web application to an Amazon Aurora database.

### 03 - DynamoDB Data Loading
Create and populate DynamoDB tables using AWS CLI.

### 04 - DynamoDB Queries & Transactions
Perform queries and transactions using DynamoDB via CLI and Console.

### 05 - Database Visualization
Visualize relational data using Amazon RDS and Amazon QuickSight.

---

## 🧰 Technologies Used

- Amazon Aurora
- Amazon RDS
- Amazon DynamoDB
- AWS CLI
- Amazon QuickSight

---

## 🎯 Goal

To provide practical, step-by-step AWS database projects that help learners move from foundational database concepts to real-world cloud implementation, data querying, and visualization.

This series is ideal for anyone preparing for Cloud, Data, or DevOps roles.

---

## 📈 Learning Outcomes

By completing this series, you will learn how to:

- Deploy and connect cloud databases
- Work with relational and NoSQL systems
- Load and manage structured data
- Run queries and transactions
- Visualize data for insights
